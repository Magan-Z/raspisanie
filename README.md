# Расписание ИМФИТ

Расписание всего института (ОФО, ОЗФО, магистратура) в телефоне:
- **Android** — приложение с виджетами (папка `app/`);
- **iPhone** — подписка на календарь `.ics` через страницу сайта.

Подробное устройство — в [АРХИТЕКТУРА.md](АРХИТЕКТУРА.md).

```
data/                     ← парсер: превращает xlsx в JSON и календари
  config.json             ← настройки: звонки, недели, праздники, исправления опечаток
  sources/raspisanie.xlsx ← сам файл расписания (новый кладём под этим же именем)
  schedule_parser/        ← код парсера на Python
  tests/                  ← автоматические проверки
  web/index.html          ← страница подписки для iPhone
.github/workflows/        ← автоматическая публикация на GitHub Pages
app/                      ← приложение для Android (Flutter)
```

## Как обновить расписание (когда пришёл новый файл в WhatsApp)

1. Сохраните xlsx из WhatsApp на телефон или компьютер.
2. Откройте репозиторий на github.com → папка `data/sources/`.
3. **Add file → Upload files** → перетащите файл. **Важно:** файл должен называться `raspisanie.xlsx`
   (переименуйте перед загрузкой, тогда старый заменится).
4. Внизу нажмите **Commit changes**.
5. Через 1–2 минуты сайт обновится сам. Посмотреть ход можно во вкладке **Actions**:
   зелёная галочка — всё опубликовано; красный крестик — файл не прошёл проверки,
   на сайте осталась прошлая версия, а GitHub пришлёт письмо. Что именно не так,
   написано в журнале шага «Разбор расписания» или «Отчёт в журнал».

Если начался **новый семестр** — поменяйте в `data/config.json` поля `semester` (id, start, end)
и при необходимости `weekAnchor` (понедельник, с которого идёт «1 неделя»).

## Этап 0. Парсер — как запустить и проверить на своём компьютере

Нужен Python 3.12 или новее. Все команды — в Терминале, из папки проекта.

**Один раз** — создать «виртуальное окружение» (отдельную папку с библиотеками для проекта):

```bash
python3 -m venv .venv
```

```bash
.venv/bin/pip install -r data/requirements.txt
```

**Запустить тесты** (проверяют контрольные факты из §11 АРХИТЕКТУРЫ: число групп,
все пары 1 БИ-25, недели, календари):

```bash
.venv/bin/python -m pytest data/tests
```

В конце должно быть написано `passed` и ни одного `failed`.

**Запустить парсер:**

```bash
cd data && ../.venv/bin/python -m schedule_parser --out public
```

Что появится в `data/public/`:

| Файл | Что это |
|---|---|
| `report.txt` | Отчёт простым текстом: сколько групп и занятий нашлось на каждом листе, где не распознались преподаватель или аудитория. **Смотреть первым.** |
| `index.json` | Список всех групп (его первым скачивает приложение) |
| `groups/<id>.json` | Расписание одной группы, например `groups/ofo-1-bi-25.json` |
| `ics/<id>-<подгруппа>[-m/-f].ics` | Календари. `ofo-1-bi-25-1-m.ics` = 1 БИ-25, подгруппа 1, физ-ра юношей |
| `diff/latest.json` | Что изменилось по сравнению с прошлой публикацией |

**Как проверить глазами:**
- откройте `report.txt` → должно быть «Все проверки пройдены ✓», ОФО 29 групп, ОЗФО 17, Магистратура 4;
- откройте `groups/ofo-1-bi-25.json` и сравните пару-другую со своим расписанием;
- дважды щёлкните `ics/ofo-1-bi-25-1-m.ics` → откроется приложение «Календарь» на Mac
  и предложит добавить пары (можно добавить в новый календарь, а потом удалить его).

## Этап 1. Публикация на GitHub Pages

**Уже сделано:** репозиторий https://github.com/Magan-Z/raspisanie, сайт подписки **https://magan-z.github.io/raspisanie/**
(Pages включён, источник — GitHub Actions). Расписание обновляется автоматически при каждом изменении файлов в папке `data/`.
Ниже — как всё это устроено, если понадобится повторить с нуля.

### Как это настроить с нуля

Всё для публикации уже готово (`.github/workflows/publish-schedule.yml`). Осталось завести репозиторий:

1. Зарегистрируйтесь на github.com (если ещё нет).
2. Создайте **публичный** репозиторий, например `raspisanie` (GitHub Pages бесплатен только для публичных).
3. Загрузите в него содержимое этой папки (проще всего — через GitHub Desktop или командами `git`).
4. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
5. Вкладка **Actions** → «Публикация расписания» → **Run workflow**.
6. Через пару минут сайт откроется по адресу `https://<ваш-логин>.github.io/raspisanie/`.

**Как проверить:**
- откройте адрес сайта на iPhone → выберите группу → «Добавить в Календарь iPhone» → «Подписаться»;
- в Календаре появятся пары с правильными аудиториями (например, среда 7 октября, 14:40 — ЧТК и этика, 2-15);
- «сломанный» файл (например, с удалённой строкой групп) не публикуется: Actions покажет красный крестик,
  а на сайте останется прошлая версия.

**Посмотреть страницу подписки у себя на компьютере**, до GitHub:

```bash
cp data/web/index.html data/public/ && python3 -m http.server 8765 --directory data/public
```

и откройте в браузере http://localhost:8765 (остановить сервер — Ctrl+C).

## Этап 2–5. Приложение для Android — как проверить без телефона

Нужен Flutter (уже установлен через Homebrew: `brew install --cask flutter`).

**Запустить все проверки приложения** (это ядро расписания, все экраны, ДЗ, поиск и обновление с сайта на «поддельном» сервере):

```bash
cd app && flutter test
```

В конце должно быть `All tests passed!`.

**Проверить код на ошибки:**

```bash
cd app && dart analyze lib test
```

Должно быть `No issues found!`.

**Что умеет приложение сейчас:**
- первый запуск: форма → курс → группа → подгруппа → физкультура (юноши/девушки), без регистрации;
- «Сегодня»: неделя и дата, большая карточка текущей или следующей пары (аудитория крупно, до конца пары, прогресс), остальные пары дня,
  окна и большая перемена; дни листаются свайпом; в воскресенье и после последней пары открывается следующий учебный день;
- «Неделя»: переключатель 1 / 2 неделя;
- «ДЗ»: долгое нажатие на пару (или кнопка «ДЗ») → срок подставляется сам (следующее занятие предмета), можно «к лекции» / «к практике»,
  прикрепить фото; свайп вправо — выполнено, влево — удалить; на паре с ДЗ на этот день появляется значок;
- «Поиск»: где сейчас преподаватель и его пары (можно искать по фамилии, имени или отчеству — полные ФИО берутся из списка `teachers` в `data/config.json`), кто занимается в аудитории, какие аудитории свободны на выбранную пару (по этажам);
- «Настройки»: группа, подгруппа, физкультура, тема, ручной выбор недели, обновление расписания, перенос ДЗ через буфер обмена;
- работает без интернета: расписание встроено в приложение и обновляется с сайта, как только появляется связь.

**Ещё умеет приложение:**
- виджеты на главном экране (2×2 «Сейчас / Далее» и 4×2 «Сегодня»), переключаются по звонку сами;
- уведомления: за 5–30 минут до пары (настраивается или выключается), вечером в 19:00 о ДЗ на завтра, «Расписание обновилось» со списком изменений;
- личные правки: долгое нажатие на пару → изменить аудиторию / отменить пару / вернуть как было; «Мои правки» → добавить свою пару;
- раз в ~6 часов само проверяет обновления, даже когда закрыто.

**Установить на телефон:** файл `raspisanie.apk` в корне проекта (скопируйте на телефон и разрешите установку из неизвестных источников). Подробности и что ещё не проверено — в [ХОД_РАБОТ.md](ХОД_РАБОТ.md).


## Приложение для iPhone (веб-версия)

Тот же интерфейс, что и в Android-приложении, но в браузере: расписание, «Сегодня», «Неделя», домашка с файлами, поиск, свои правки, свои названия и цвета предметов, цветовые темы. **Нет только** виджетов и напоминаний (iPhone не позволяет браузеру ставить их без сервера) — для оповещений о парах подписывайтесь на календарь.

- Адрес: `https://<логин>.github.io/raspisanie/app/` (кнопка «Открыть приложение» на главной странице сайта).
- Установка на iPhone: открыть в Safari → «Поделиться» → «На экран „Домой“». Запускать значком — тогда страница открывается без адресной строки и данные не стираются.
- Данные (ДЗ, правки, вложения) хранятся в браузере iPhone, на сервер не отправляются.
- Собирается автоматически вместе с сайтом (`.github/workflows/publish-schedule.yml`); вручную: `bash scripts/build_web.sh`.
