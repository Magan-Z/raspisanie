# Как люди получают обновления

Приложение ставится из файла (APK), а не из магазина, поэтому само не обновляется. Вместо этого оно **раз в 6 часов спрашивает сайт**
(`apk.json`: последняя версия и «минимально допустимая»), только в APK для Android; веб-версия обновляется сама.

## Что видит человек

- **Вышла новая версия** → над содержимым плашка «Вышла версия 0.3.5 · Скачать · ✕». «Скачать» открывает загрузку файла в браузере телефона;
  ✕ («Позже») прячет плашку до следующей версии. Ещё строка «Доступна версия …» есть в Настройки → О приложении.
- **Версия ниже минимальной** → вместо приложения экран «Нужно обновить приложение» с кнопкой «Скачать обновление». Пройти дальше нельзя.

## Как заставить обновиться (обязательное обновление)

Открыть файл `data/min-app-version.txt`, написать в нём номер самой старой версии, которой ещё можно пользоваться (например `0.3.5`),
закоммитить и запустить публикацию сайта (или дождаться выпуска). Сайт обновит `apk.json` (поле `min`), и все версии ниже этой
при следующей проверке покажут экран «Нужно обновить». Вернуть всё назад: записать `0.0.0`.
Включайте это только когда старая версия действительно сломана (например, сервер перестал её понимать): человек без интернета экран не увидит.

## Защита от ошибок

Нет связи, непонятный ответ сайта, пустая версия в локальной сборке, `min` выше последней версии — ничего не показывается и не блокируется.
Плашка появляется только в версиях, выпущенных после её добавления (с 0.3.5): у более старых её нет.

Код: `app/lib/update_check.dart`, `app/lib/features/update_banner.dart`; тесты: `app/test/update_check_test.dart` и группа «Обновление приложения» в `app_test.dart`.
