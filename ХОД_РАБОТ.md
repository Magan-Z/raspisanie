   `sdkmanager --licenses` (принять), `sdkmanager "platforms;android-36" "build-tools;36.0.0" "platform-tools"`,

   (проверить `flutter doctor`). Принимать лицензии вместо владельца не стал: это принятие условий.
2. **GitHub:** создать публичный репозиторий, загрузить проект, Settings → Pages → Source: GitHub Actions (шаги — в README).
3. **Дата конца семестра и праздники** (в `data/config.json` стоят предположения: 26.12.2026 и 4 ноября).
4. **Название приложения** (варианты — АРХИТЕКТУРА §13). Сейчас в манифесте «Расписание».
5. По желанию: ключ подписи APK (секреты `ANDROID_KEYSTORE_BASE64`, `ANDROID_STORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`).

## Что делать дальше (когда будет Android SDK)
1. `flutter doctor` → всё зелёное для Android. `cd app && flutter build apk --debug` — убедиться, что собирается
   (возможные проблемы: пакет `sqlite3` собирает/скачивает нативную библиотеку через build hooks; `image_picker`).
2. **Этап 3.** `home_widget` + Kotlin (Jetpack Glance): виджеты 2×2 и 4×2 по §7.6. Dart-часть: `widget_bridge/widget_sync.dart` вызывает
   `buildWidgetSnapshot` + `encodeWidgetSnapshot` и пишет в SharedPreferences через `home_widget` после синхронизации, смены профиля и ДЗ.
   Kotlin сам выбирает текущую/следующую пару из снимка по часам; `AlarmManager.setWindow` на границах пар; `Chronometer` для отсчёта;
   «+ ДЗ» открывает `raspisanie://homework/new?subject=…` (в приложении: принять ссылку и вызвать `showAddHomework`).
3. **Этап 5 (платформа).** `flutter_local_notifications` + `workmanager`: `planNotifications` уже считает, что и когда показать
   (стабильные id) — осталось поставить их `zonedSchedule` и перепланировать после синхронизации; фоновая проверка раз в ~6 ч.
   «Расписание обновилось»: `diff/latest.json` сайта (формат — АРХИТЕКТУРА §4) → уведомление и баннер на «Сегодня».
   Экран личных правок (`Override` и таблица `overrides` уже есть).
4. Проверить на реальном телефоне: офлайн (авиарежим), тёмная тема, крупный шрифт, TalkBack.
