## Этап 5 — уведомления, личные правки, фон (Android)
- **Уведомления:** `flutter_local_notifications` (+ `timezone`). Что и когда показывать, считает `domain/notification_plan.dart`; ставит `notifications/notification_gateway.dart`
  (`zonedSchedule`, точные будильники через `USE_EXACT_ALARM`, каналы «Пары» / «Домашка» / «Обновления расписания», своя иконка `ic_notification`).
  Пересчёт — `app_outputs.dart` (`replanNotifications`) после любого изменения расписания, ДЗ, правок, настроек и при возврате в приложение.
  Разрешение (Android 13+) спрашивается один раз при первом запуске; в «Настройках» — время напоминания (выкл / 5 / 10 / 15 / 30 мин), вечернее ДЗ, кнопка «Разрешить уведомления».
- **Личные правки** (таблица `overrides`): долгое нажатие на пару → «Добавить ДЗ» / «Изменить на этот день» (аудитория, преподаватель, заметка) / «Отменить пару» /
  «Вернуть как было»; «Мои правки» на каждом дне — список правок и «Добавить свою пару». Правки учитываются в «Сегодня», виджетах и уведомлениях
  (`features/overrides/day_edits.dart`, `data/repositories/overrides_repository.dart`).
- **Фон:** `workmanager`, раз в ~6 ч (`background/background_sync.dart`): синхронизация → «Расписание обновилось» → снимок виджетов → план уведомлений.
  Задача работает в отдельном движке Flutter, поэтому данные виджетам передаёт пакет **`home_widget`** (он регистрируется во всех движках);
  собственный канал `raspisanie/widget` убран, Kotlin читает снимок из `HomeWidgetPreferences` (ключ `snapshot`).
- **Проверено на эмуляторе (Android 15):** окно разрешения; уведомление «ЧТК и этика → 2-15 · Ахмадова М.П. · через 10 мин» ровно в 14:30 при пустом приложении;
  отмена пары убирает её с экрана и из снимка виджетов; фоновая задача (принудительно, с переводом часов) выполняется с `Worker result SUCCESS` и обновляет снимок и виджет
  при закрытом приложении; релизный APK запускается и ставит 24 будильника.
- **Как принудительно запустить фон в эмуляторе:** `adb shell cmd jobscheduler run -f -n androidx.work.systemjobscheduler ru.raspisanie.raspisanie <ID>`
  (ID — из `dumpsys jobscheduler`, у нас обычно 1, 2, …); WorkManager не запускает периодическую задачу раньше срока, поэтому сначала сдвиньте часы эмулятора
  на 6+ часов вперёд (`adb root; adb shell date MMDDhhmmYYYY.ss`).
- **Не проверено:** реальные телефоны (экономия батареи Xiaomi/Huawei может убивать фон и будильники — нужен тест у владельца), сеть до настоящего сайта (адрес ещё не задан),
  тап по уведомлению (открывает приложение, без перехода на нужный день).
- **Известные ограничения:** на Android 12+ с Doze уведомления точные только при разрешённых «будильниках и напоминаниях» (`USE_EXACT_ALARM` выдаётся автоматически;
  если этого не будет в магазине приложений — перейти на `SCHEDULE_EXACT_ALARM` и запросить у пользователя).

## Этап 3 — виджеты (Android)
Лицензии Android SDK владелец принял 2026-10-08 (в чате), SDK ставился в `/opt/homebrew/share/android-commandlinetools`.
- **Данные:** `domain/widget_snapshot.dart` собирает снимок на 7 дней → `widget_bridge/widget_sync.dart` отдаёт его каналом
  `raspisanie/widget` → `MainActivity.kt` кладёт в SharedPreferences `raspisanie_widget` → виджеты читают оттуда без Flutter.
  Снимок пересобирается при изменении расписания, ДЗ, профиля и при возврате в приложение (`home_shell.dart`).
- **Kotlin** (`app/android/app/src/main/kotlin/.../widget/`): `WidgetLogic.kt` — чистая логика (текущая/следующая пара, «сегодня/завтра»,
  ближайшая граница) без Android-классов; `WidgetRenderer.kt` — RemoteViews; `WidgetUpdater.kt` — обновление + `AlarmManager.setWindow`
  на ближайшую границу пары (не реже раза в час); `WidgetReceivers.kt` — провайдеры, будильник, перезагрузка.
  Layouts: `res/layout/widget_now_next.xml` (2×2), `widget_today.xml` (4×2); цвета светлые/тёмные — `res/values*/colors.xml`.
- **Отступление от спецификации:** обычные `RemoteViews`, а не Jetpack Glance: у Glance нет `Chronometer`, а обратный отсчёт должен тикать
  сам; плюс меньше риска со сборкой. Пакет `home_widget` не используется — свой канал (меньше зависимостей).
- **«+ ДЗ»:** ссылка `raspisanie://homework/new?subject=…` → `MainActivity.onNewIntent`/`getInitialLink` → канал `raspisanie/links` →
  `HomeShell._openLink` открывает вкладку «ДЗ» и окно «Новое ДЗ» с предметом.
- **Тесты:** Dart — `test/widget_bridge_test.dart`; Kotlin — `app/android/app/src/test/.../WidgetLogicTest.kt`
  (`cd app/android && ./gradlew testDebugUnitTest`).
- **Проверено на эмуляторе** (Pixel 6, Android 15, время выставлено на среду 7.10.2026 13:30 МСК): оба виджета добавляются из списка
  «Расписание → Сейчас / Далее, Сегодня»; 2×2 показывает «СЕЙЧАС · Техн. предп. · 2-05 · до конца 58:22» с тикающим отсчётом и значком «Л»;
  4×2 показывает пары дня с подсветкой идущей; кнопка «+ ДЗ» открывает окно «Новое ДЗ» с предметом и автосроком; в 14:40:00
  будильник сам переключил подсветку на «ЧТК и этика» при закрытом приложении.
- **Не проверено:** реальные телефоны (агрессивная экономия батареи Xiaomi/Huawei), тёмная тема виджетов, переключение 2×2 на «Далее» после
  конца последней пары, ограничения на будильники в Android 14+ на физическом устройстве.
- **Известные ограничения:** снимок рассчитан на 7 дней — если приложение не открывать дольше недели, виджет покажет «Пар нет»
  (план: `workmanager` раз в ~6 ч пересобирает снимок — этап 5). Точные будильники не используются: переключение может задержаться
  до минуты. В списке виджетов вместо превью — значок Flutter (можно добавить `previewLayout`). Если 4×2 не помещается рядом с 2×2,
  лаунчер просто не даёт его разместить (это поведение лаунчера, а не ошибка).

## Как запустить эмулятор и проверить виджеты (для следующего исполнителя)
Всё поставлено вручную в `/opt/homebrew/share/android-commandlinetools` (SDK 36, build-tools 36.0.0, platform-tools, NDK 28.2.13676358,
emulator 37.3.3, образ `system-images;android-35;google_apis;arm64-v8a`, AVD `pixel35` в `~/.android/avd`). Скачивание Gradle'ом/sdkmanager'ом
здесь очень медленное (~150 КБ/с на один поток), поэтому NDK, эмулятор и образ качались вручную параллельными `curl -r` кусками с проверкой sha1.
```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@17 ANDROID_HOME=/opt/homebrew/share/android-commandlinetools PATH=/opt/homebrew/opt/openjdk@17/bin:$PATH
$ANDROID_HOME/emulator/emulator -avd pixel35 -no-window -no-audio -gpu swiftshader_indirect &   # без окна; скриншоты: adb exec-out screencap -p
cd app && flutter build apk --debug && $ANDROID_HOME/platform-tools/adb install -r build/app/outputs/flutter-apk/app-debug.apk
adb root && adb shell "date 100713302026.00"      # поставить время (МСК; часовой пояс уже Europe/Moscow)
```
Профиль можно задать без экранов выбора: положить `shared_prefs/FlutterSharedPreferences.xml` (`flutter.form`, `flutter.groupId`, `flutter.subgroup`, `flutter.pe`)
через `adb shell run-as ru.raspisanie.raspisanie`. Виджет на экран ставится перетаскиванием из списка виджетов (`adb shell input draganddrop`).
Kotlin-тесты: `cd app/android && ./gradlew :app:testDebugUnitTest` (14 тестов; без `:app:` Gradle запустит и тесты плагинов — у `image_picker` они падают из-за кириллицы в пути).
