## Этап 3 — виджеты (Android)
Лицензии Android SDK владелец принял 2026-10-08 (в чате), SDK ставился в `/opt/homebrew/share/android-commandlinetools`.
- **Данные:** `domain/widget_snapshot.dart` собирает снимок на 7 дней → `widget_bridge/widget_sync.dart` отдаёт его каналом
  `raspisanie/widget` → `MainActivity.kt` кладёт в SharedPreferences `raspisanie_widget` → виджеты читают оттуда без Flutter.
  Снимок пересобирается при изменении расписания, ДЗ, профиля и при возврате в приложение (`home_shell.dart`).
- **Kotlin** (`app/android/app/src/main/kotlin/.../widget/`): `WidgetLogic.kt` — чистая логика (текущая/следующая пара, «сегодня/завтра»,
  ближайшая граница) без Android-классов; `WidgetRenderer.kt` — RemoteViews; `WidgetUpdater.kt` — обновление + `AlarmManager.setWindow`
  на ближайшую границу пары (не реже раза в час); `WidgetReceivers.kt` — провайдеры, будильник, перезагрузка.
  Layouts: `res/layout/widget_now_next.xml` (2×2), `widget_today.xml` (4×2); цвета светлые/тёмные — `res/values*/colors.xml`.
- **Отступление от спецификации:** обычные `RemoteViews`, а не Jetpack Glance: у Glance нет `Chronometer`, а обратный отсчёт должен тикать
  сам; плюс меньше риска со сборкой. Пакет `home_widget` не используется — свой канал (меньше зависимостей).
- **«+ ДЗ»:** ссылка `raspisanie://homework/new?subject=…` → `MainActivity.onNewIntent`/`getInitialLink` → канал `raspisanie/links` →
  `HomeShell._openLink` открывает вкладку «ДЗ» и окно «Новое ДЗ» с предметом.
- **Тесты:** Dart — `test/widget_bridge_test.dart`; Kotlin — `app/android/app/src/test/.../WidgetLogicTest.kt`
  (`cd app/android && ./gradlew testDebugUnitTest`).
- **Известные ограничения:** снимок рассчитан на 7 дней — если приложение не открывать дольше недели, виджет покажет «Пар нет»
  (план: `workmanager` раз в ~6 ч пересобирает снимок — этап 5). Точные будильники не используются: переключение может задержаться
  до минуты.
